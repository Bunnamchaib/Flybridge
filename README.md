# FlyVibe PWA

ไฟล์พร้อมสำหรับ GitHub Pages

## วิธีใช้
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปที่ root ของ repo `Bunnamchaib/Flybridge`
2. GitHub → Settings → Pages
3. Source: Deploy from a branch
4. Branch: `main` / root
5. เปิด URL ของ GitHub Pages

## iPhone
เปิดเว็บด้วย Safari → Share → Add to Home Screen

## ฟังก์ชัน
- สแกน QR จากกล้อง
- อัปโหลดรูป QR
- ตรวจสอบว่า QR เป็น http/https URL
- เปิด Voice Room อัตโนมัติ
- PWA / Add to Home Screen
- Apple touch icon
